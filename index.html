Background

I'm a BSc Software Engineering student with a passion for cybersecurity. I build and experiment in my home lab, where i work with Windows Server (Active Directry), Kali Linux, and virtualized environments to learn network security, enumaration, and defence fundamentals.

Beyond the home lab i sharpen my skills on TryHackMe through hands-on labs covering networking, web security, Linux and CTF challenges.

More recently I've been combining that security foundation with AI, starting with CyberSec AI, a fully offline RAG assistant I built from scratch to learn how local LLMs, embeddings, and vector search actually work, then applying those same foundations to Sentra: an intrusion detection system that explains its own reasoning using SHAP, adapts to a network's own traffic baseline, and runs a local LLM to summarize alerts for an analyst, all without sending any data to the cloud.

sentra.py

Sentra — AI-Powered SOC Copilot

An intrusion detection system that explains its own decisions. Trained a Random Forest classifier on real network traffic (99.9% recall across brute-force and DoS attacks), added a SHAP explainability layer, a custom baseline-learning module that adapts to what's "normal" for a specific network, MITRE ATT&CK mapping, and a locally-run LLM (Llama 3.2 via Ollama) that turns raw detections into plain-English analyst summaries — no cloud dependency.

cybersec_ai.py

CyberSec AI — Local LLM Cybersecurity Assistant

A fully offline retrieval-augmented generation (RAG) assistant built from first principles as groundwork for Sentra — no paid API, no cloud dependency. Documented every stage from a single Ollama API call through prompt engineering and conversation memory, to embeddings (nomic-embed-text), a FAISS vector index with save/load persistence, and automatic re-indexing when the knowledge base changes. Includes a public build log with the real bugs hit along the way (an IndexError, a retrieval-scoring issue still being investigated).
